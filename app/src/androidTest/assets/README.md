# Live tracking test fixture

`grace_hopper.jpg` is the Grace Hopper portrait from Matplotlib's sample data:
https://github.com/matplotlib/matplotlib/blob/main/lib/matplotlib/mpl-data/sample_data/grace_hopper.jpg

Original photograph: James S. Davis, U.S. Navy, 1984; Naval History and Heritage Command, NH 96919-KN.
Public-domain source information: https://commons.wikimedia.org/wiki/File:Grace_Hopper.jpg

Used only in the instrumentation APK to exercise the actual bundled MediaPipe models, including blank and two-face frames. It is not patient data, a clinical accuracy dataset, or an example of a suitable unobstructed hairline photograph. It is not included in the production APK.
